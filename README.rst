*******
Summary
*******

``lib_voice`` is a collection of DSP components used to build a front-end voice processing pipeline.

********
Features
********

* Acoustic Echo Canceller
* Delay Estimator
* Interference Canceller
* Voice to Noise Ratio Estimator
* Noise Suppressior
* Automatic Gain Controller
