Overview
--------

This demo application shows a simple use of the Direction-Of-Arrival
library. It uses the microphone array library to get samples from six
microphones and then displays the determined direction of arrival
on the LEDs.

Please see AN00220 for details on capturing data from the microphones.

|newpage|

The DOA call
------------

In order to use the DOA functionality you need to add
``lib_voice`` to your ``Makefile``::

  USED_MODULES = ... lib_voice ...

You also have to include the ``lib_voice_naive_doa.h`` header file in your
source in order to access the DOA functions.

.. literalinclude:: app_doa_example.xc
   :start-on: include "lib_voice
   :end-before: include "mic_array.h"

The application note also uses the Microphone Array support libraries to get
data from the microphones and the |I2C| library in order to configure the
PLL. Therefore the following need to be added to the ``Makefile`` ::

  USED_MODULES = ... lib_mic_array lib_mic_array_board_support lib_i2c ...

And the following includes have to be added to your application:

.. literalinclude:: app_doa_example.xc
   :start-on: include "mic_array.h"
   :end-on: include "i2c.h"

Demo Hardware Setup
-------------------

#. Connect the xTAG-2 or xTAG-3 to Microphone Array Ref Design v1.
   
#. Connect the xTAG-2 or xTAG-3 USB connector to the USB connector on
   your development PC using a USB cable.
   
#. Connect the Microphone Array Ref Design v1 to your development PC
   using another USB cable.

Launching the demo application
------------------------------

Once the application source code is imported into the tools you can then
build the project which will generate the binary file required to run the
demo application.

Once the application has been built you need to download the application
binary code onto the Microphone Array Ref Design v1. Here you use the
tools to load the application over JTAG onto the xCORE multicore
microcontroller.

Then click **Run**.

Alternatively, from the command line build the application, by doing a call
to ``xmake``, then run using ``xrun app_doa_example.xe``.

The leds will indicate the direction of arrival.

Task setup
----------

The DOA example comprises a single function call:

.. literalinclude:: app_doa_example.xc
   :start-on: int angle = 
   :end-before: lb.set_led_brightness

This function call passes the sample values of each of the six microphones
to the DOA estimator, which will return one of two sorts of values:

* The value **LIB_VOICE_DOA_NOTHING** indicates that there is not enough
  sound to calculate a direction

* A value between 0 and 359 (inclusive), indicates the angle of the sound.
  An angle of zero indicates that the sound came from microphone 1, and
  positive angles move counter clockwise on the board, as shown in Figure 1.

.. figure:: angle.pdf
            :width: 50%

            How to interpret the return value

The calculation assumes that:

* there are six microphones in a hexagonal arrangement with a radius of 48 mm

* the sample rate is 16 kHz

* that the sound originates roughly planar to the six microphones
